A one-line joke about working beside an AI coding agent, written out by a small deterministic program: ask it to fix the bug before the demo, and it deletes the feature, the tests, and the error message — then leaves a comment that just says "trust me".

## Run it

```sh
node main.ts
```

The program writes the joke to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write elsewhere). No network, no dependencies, same bytes on every run.
